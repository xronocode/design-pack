# Каталог стилей — полные токены

Формат каждого стиля: характер → палитра → типографика → шкалы → моушн → сценарии → нельзя. Цвета указаны hex'ами; роли: bg / surface / text / muted / accent (+ accent-text при необходимости).

---

## 1. `swiss` — швейцарская типографика

**Характер:** содержание и есть дизайн; сетка, контраст масштабов, ноль украшений.

| Роль | Значение |
|---|---|
| bg | `#FFFFFF` |
| surface | `#F4F4F4` |
| text | `#111111` |
| muted | `#6B6B6B` |
| accent | `#E30613` (классический красный) |

**Типографика:** display — `Inter Tight` / `Neue Haas Grotesk` 700, трекинг −0.02em; body — `Inter` 400/500. Scale (rem): 0.875 / 1 / 1.25 / 1.5 / 2 / 3 / 4.5. Заголовки — влево, шкала агрессивная (соседние ступени отличаются в ≥1.5 раза).

**Шкалы:** spacing 4/8/16/24/48/96; сетка 12 колонок, gap 24. Радиусы: **0 везде**. Тени: **запрещены**.

**Моушн:** без анимации, кроме мгновенных смен состояния (120 мс, linear).

**Сценарии:** B2B, отчёты, дашборды, документация, аналитика — везде, где главное данные.

**Нельзя:** тени, радиусы, декоративные элементы, курсив, центрированные абзацы.

---

## 2. `editorial` — журнальный

**Характер:** чтение как ценность; крупная serif-типографика, воздух, тёплая бумага.

| Роль | Значение |
|---|---|
| bg | `#FAF7F2` (бумага) |
| surface | `#FFFFFF` |
| text | `#1A1612` |
| muted | `#8A8078` |
| accent | `#7A1E1E` (бордо) |

**Типографика:** display — `Fraunces` / `Playfair Display` 600 (прямой, курсив — точечно); body — `Source Serif 4` для длинных текстов или `Inter` для UI. Мерная колонка 65–75ch. Буквицы и врезки приветствуются.

**Шкалы:** spacing 8/16/32/64/128; вертикальный ритм по baseline. Радиусы: 0–4px. Тени: нет; разделители — тонкие линии `#E5DED4`.

**Моушн:** сдержанное появление при скролле (fade 300 мс), без сдвигов.

**Сценарии:** медиа, блоги, лонгриды, портфолио, премиальный контент.

**Нельзя:** стеклянность, неон, «AI-бежевый» без этой системы, больше одного курсива.

## 3. `neo-brutalist`

**Характер:** жёсткие рамки, плоские сдвиговые тени, насыщенные заливки, ноль полутонов.

| Роль | Значение |
|---|---|
| bg | `#FFF8E7` |
| surface | `#FFFFFF` |
| text | `#0F0F0F` |
| accent | `#FF5D01` (апельсин) + вторичные: `#2F7CF6`, `#FFD131`, `#22C55E` |

**Типографика:** display — `Space Grotesk` 700 / `Archivo Black`; body — `Space Grotesk` 400. Заголовки капсом с трекингом +0.02em допустимы.

**Шкалы:** spacing 8/16/24/48. Радиусы: 0 (или нарочитый один размер 12px — но системно). Тени: `4px 4px 0 #0F0F0F`, `8px 8px 0` для hover-подъёма. Границы: `2–3px solid #0F0F0F` у всего.

**Моушн:** быстрые и жёсткие: hover — сдвиг 2px за 100 мс без ease.

**Сценарии:** промо-страницы, ивенты, промо-акции, молодые дерзкие продукты.

**Нельзя:** полупрозрачность, blur, мягкие тени, градиенты, пастель.

---

## 4. `soft-minimal`

**Характер:** спокойный consumer-минимализм: скругления, пастель, много воздуха.

| Роль | Значение |
|---|---|
| bg | `#FBFBFD` |
| surface | `#FFFFFF` |
| text | `#23262E` |
| muted | `#7A7F8C` |
| accent | `#5B6CFF` (или бренд), акцент-фон `#EEF0FF` |

**Типографика:** display и body — `DM Sans` 500/400; заголовки умеренного размера, межстрочный 1.6 у body.

**Шкалы:** spacing 8/12/16/24/40/64. Радиусы: 12/16/24 (карточки 16). Тени: одна мягкая `0 1px 3px rgba(23,26,33,.08)` + `0 8px 24px` при hover.

**Моушн:** мягкие ease-out 200–250 мс; лёгкий scale 1.01 при hover карточек.

**Сценарии:** мобильные приложения, onboarding, wellness, финансы для людей.

**Нельзя:** резкие контрасты, тяжёлые рамки, жёсткие тени, неон.

## 5. `terminal-mono`

**Характер:** всё — код; инженерная честность, минимум хрома.

| Роль | Значение |
|---|---|
| bg | `#0D1117` |
| surface | `#161B22` |
| text | `#C9D1D9` |
| muted | `#8B949E` |
| accent | `#3FB950` (терминальный зелёный), вторичный `#58A6FF` |

**Типографика:** всё — `JetBrains Mono` / `IBM Plex Mono` 400; заголовки тем же моно, крупнее + капс с трекингом. Табличные цифры везде.

**Шкалы:** spacing 8/16/24/32. Радиусы: 0–4. Границы: `1px solid #21262D`. Тени нет; глубина — фоном surface.

**Моушн:** появление текста «печатью» допустимо один раз в hero; остальное мгновенно.

**Сценарии:** devtools, CLI-лендинги, логи, мониторы, техническая документация.

**Нельзя:** serif, градиенты, картинки-декорации, скругления-пилюли.

## 6. `nordic-light`

**Характер:** скандинавский SaaS: белый, тонкие линии, функциональная сдержанность.

| Роль | Значение |
|---|---|
| bg | `#FFFFFF` |
| surface | `#F7F9FB` |
| text | `#12263A` |
| muted | `#5E718A` |
| accent | `#0F62FE` |

**Типографика:** display/body — `IBM Plex Sans` 600/400; плотные таблицы с `tabular-nums`.

**Шкалы:** spacing 8/16/24/32/56. Радиусы: 6/8. Границы `1px solid #DCE3EC` — основной разделитель, тени почти нет.

**Моушн:** 150 мс ease-out на состояния.

**Сценарии:** SaaS, админки, корпоративные продукты, таблицы и формы.

**Нельзя:** тени-xl, большие радиусы, яркая палитра, декоративные фоны.

## 7. `retro-web`

**Характер:** наивный интернет 90-х: системные шрифты, браузерные рамки, честный HTML.

| Роль | Значение |
|---|---|
| bg | `#C0C0C0` / `#FFFFFF` |
| text | `#000080` для ссылок, `#000000` текст |
| accent | `#FF0000` + `marquee`-классика в малых дозах |

**Типографика:** `Times New Roman` / системный стек; заголовки `<h1>`-классики, `Comic Sans MS` — осознанная ирония, не по умолчанию.

**Шкалы:** spacing 8/16; таблицы как layout допустимы (в шутку). Радиусы 0; beveled кнопки `border: 2px outset`.

**Моушн:** `blink` — только один элемент на страницу, как мем.

**Сценарии:** персональные сайты, зины, ироничные проекты, арт.

**Нельзя:** применять к продуктовым UI без явного запроса; смешивать с современным glass/gradient.

## 8. `fintech-dark`

**Характер:** плотные данные на тёмном; точность, тонкие делители, отсутствие декора.

| Роль | Значение |
|---|---|
| bg | `#0A0E14` |
| surface | `#111722` |
| text | `#E6EAF2` |
| muted | `#7E8AA0` |
| accent | `#4ADE80` (рост) / `#F87171` (падение) / `#60A5FA` (действие) |

**Типографика:** body — `Inter` 400/500; данные — `IBM Plex Mono` tabular. Плотность высокая: строки 40px, межстрочный 1.4.

**Шкалы:** spacing 4/8/16/24. Радиусы 4. Делители `1px solid #1B2432`. Тени нет.

**Моушн:** обновление цифр без анимации; спарклайны — 250 мс переход.

**Сценарии:** трейдинг, терминалы, бенчмарки, мониторинги.

**Нельзя:** пастель, скругления-пилюли, декоративные тени, избыточный моушн, эмодзи.

## 9. `playful-organic`

**Характер:** рукотворность и тепло: blob-формы, рукописные акценты, живые цвета.

| Роль | Значение |
|---|---|
| bg | `#FFF9F0` |
| text | `#3D2C29` |
| accent | `#FF7A59` + поддержки: `#FFC94D`, `#79B4A9` |

**Типографика:** display — `Baloo 2` / рукописный акцент `Caveat` (точечно); body — `Nunito` 400.

**Шкалы:** spacing 8/16/24/40. Радиусы: 16/28 + blob-формы через `border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%`.

**Моушн:** пружинные ease (`cubic-bezier(.34,1.56,.64,1)`) 300 мс на интерактив.

**Сценарии:** детские и образовательные продукты, комьюнити, некоммерческие проекты.

**Нельзя:** тёмные плотные темы, строгие сетки без смягчения, моно-шрифты в контенте.

## 10. `blueprint`

**Характер:** чертёж/спека: тонкая сетка, выноски, моно-подписи, точность.

| Роль | Значение |
|---|---|
| bg | `#0B3D91` (классический blueprint) или `#FFFFFF` |
| линии/текст | `#FFFFFF` / `#0B3D91` |
| accent | `#FFD23F` (маркер) |

**Типографика:** подписи и данные — `IBM Plex Mono` 400; заголовки — тот же моно, капс, трекинг +0.08em. Линейка-сетка фоном `rgba(255,255,255,.08)` шаг 24px.

**Шкалы:** spacing 8/24 (кратно сетке). Радиусы: 0. Штрихи: `1px solid`, пунктир для выносок, `2px` для контуров.

**Моушн:** нет; «рисование» линий — только в декоративном hero.

**Сценарии:** тех-спеки, архитектурные схемы, hardware, лендинги инженерных продуктов.

**Нельзя:** тени, скругления, фотографии без наложения сетки, serif.

## 11. `luxury-mono`

**Характер:** модный премиум: чёрно-белое, огромный serif, металлический акцент, экстремальные отступы.

| Роль | Значение |
|---|---|
| bg | `#0A0A0A` или `#F5F3EF` |
| text | инверсия фона |
| accent | `#C9A96A` (шампань) — только линии, мелкие детали, не заливки |

**Типографика:** display — `Cormorant Garamond` 300/500, размеры до 8rem, трекинг капса +0.2em; body — `Inter` 300, 14px, трекинг +0.02em.

**Шкалы:** spacing 16/32/64/128; вертикальные ритмы «пустой сцены». Радиусы 0. Тени нет.

**Моушн:** медленные fade 500–700 мс; параллакс допустим.

**Сценарии:** мода, премиум-сервисы, события, портфолио high-end.

**Нельзя:** кнопки-заливки (только контур/подчёркивание), эмодзи, плотные сетки карточек, неон.

## 12. `cyber-neon`

**Характер:** ночная энергия: тёмная база, светящиеся акценты, техно-детали.

| Роль | Значение |
|---|---|
| bg | `#05010F` |
| surface | `#0E0A1F` |
| text | `#EDEBFF` |
| accent | `#00F0FF` (cyan) + `#FF2EC4` (magenta) |

**Типографика:** display — `Unbounded` / `Orbitron` 600; body — `Inter` 400; данные — моно.

**Шкалы:** spacing 8/16/32. Радиусы 0–8. Свечение: `box-shadow: 0 0 24px rgba(0,240,255,.35)` — не более чем на 2 элементах. Границы `1px solid rgba(0,240,255,.4)`.

**Моушн:** глоу-пульс 2–4с на hero-элементе; скан-линии фоном на одном блоке.

**Сценарии:** игры, киберспорт, клубные ивенты, ночные сервисы.

**Нельзя:** применять в корпоративном/медицинском/финансовом UI (читаемость и доверие), больше двух источников свечения на экран.
